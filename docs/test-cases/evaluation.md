# 기준표·평가 기록 (TC-EVAL)

대상: 기준 버전 선택(`CriteriaService`), 평가 기록(`EvaluationService`), Flyway 첫 기준 버전 ([업무 명세 5장·6장·9장](../spec.md#5-기준표-db-버전))

- **관점:** 정상(평가 기록 저장, 기준 버전 선택), 예외(적용 중인 기준 버전 없음), 경계(적용 시각이 아직 오지 않은 버전), 보안(연소득·DTI 암호문)을 봅니다.
- 평가 API는 4단계라서 이번에는 서비스를 직접 불러 확인합니다(DB 포함, `@SpringBootTest`).
- 2단계에서 구현과 함께 자동화했습니다. 버전 선택 테스트는 만든 버전을 끝나면 지워서, 같은 DB를 쓰는 다른 테스트가 첫 버전으로 판정하게 합니다.
