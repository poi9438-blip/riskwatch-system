# 뼈대 (TC-BASE)

대상: `SecurityConfig`, `TraceIdFilter`, `TraceIds`, `JacksonTimeConfig`, `StartupWarmUp`, `application.yml`(actuator)

- **traceId 규칙:** 번호는 요청을 시작한 서비스만 만듭니다. HomeFin이 보낸 `X-Trace-Id`(`hfm-…`)가 형식(영문·숫자·`._-`, 64자 이하)에 맞으면 그대로 쓰고, 없거나 틀리면 `rw-UUID`를 만듭니다.
- **보안 기본값:** 뼈대 단계에는 인증 방법이 없어서 `/actuator/health` 외 모든 주소가 401입니다. 서비스 토큰·운영자 JWT는 다음 단계에서 추가합니다.
- **시작 준비 ([#2](../known-issues.md)):** 띄운 직후 첫 평가는 처음 실행 비용(요청 처리·토큰 확인, 첫 JPA 조회, 첫 저장) 때문에 1.7초 넘게 걸려 HomeFin 응답 제한(2초)을 넘었습니다. 그래서 시작할 때 평가 경로를 한 번 미리 실행합니다: 요청 본문 읽기·검증, 토큰 확인, 기준표 조회·규칙 엔진·평가 저장을 하고 저장은 롤백합니다. 끝나기 전에는 `/actuator/health`가 503이라 compose가 healthy로 보지 않고, HomeFin·FinFlow도 시작을 기다립니다. 미리 실행이 실패해도 시작은 막지 않습니다(첫 요청만 느림).
- **경계·보안 관점:** traceId 64/65자 경계와 허용 안 되는 문자(로그 위조 방지)를 확인합니다. 정상·예외 관점은 아래 행에 있습니다.
