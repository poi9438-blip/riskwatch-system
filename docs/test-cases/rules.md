# 심사 규칙 엔진 (TC-RULE)

대상: `RuleEngine` (입력 + 기준값 → 판정·근거, DB 없이 단위 테스트) ([업무 명세 4장·5장](../spec.md#4-심사-규칙))

- **관점:** 정상(모두 충족), 예외(기준 누락), 경계(각 기준값 정확히 같음 / 1 초과), 보안 해당 없음(입력 검증은 평가 API 단계 TC에서).
- 기준값은 첫 기준 버전(`2026-10-26`) 값으로 확인합니다. 금액은 원, DTI·LTV는 비율(0.60 = 60%).
- **지역을 비워 보내면** 생애최초 LTV 우대(80%)를 주지 않습니다(수도권일 수도 있어서 보수적으로, HomeFin과 같음).
- **주택 가격 × LTV**는 원 단위 아래를 버립니다.
- 2단계에서 구현과 함께 자동화했습니다. 기대값은 명세 5장 표를 옮긴 `SpecCriteria`를 씁니다(Flyway 첫 버전 값 확인 TC-EVAL-205도 같은 표를 씀).
