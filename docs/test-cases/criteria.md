# 심사 기준 변경·조회 (TC-CRIT)

대상: 운영자 기준표 API (`/api/admin/criteria…`), 평가 기록 목록 (`/api/admin/evaluations`) ([업무 명세 5장·7장](../spec.md#5-기준표-db-버전))

- **관점:** 정상(새 버전 만들기·조회·이력), 예외(예약된 버전이 있음, 같은 버전 이름), 경계(값 범위 양 끝, 적용 시각 과거/즉시/미래), 보안(만든 사람은 토큰으로 정함, 기준 버전은 바꾸거나 지울 수 없음).
- **새 버전 = 지금 적용 중인 버전 + 바꾼 값.** 바꾸지 않은 값은 그대로 복사합니다.
- **예약은 하나만:** 적용 시각이 아직 오지 않은 버전이 있으면 새 버전을 만들 수 없습니다(409). 예약이 두 개면 먼저 예약한 변경이 나중 버전에 복사되지 않아 사라질 수 있어서입니다.
- 3단계에서 구현과 함께 자동화했습니다. 테스트가 만든 버전은 끝날 때마다 지워서, 같은 DB를 쓰는 다른 테스트가 첫 버전으로 판정하게 합니다.
