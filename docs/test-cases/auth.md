# 운영자 인증 (TC-AUTH)

대상: 운영자 로그인, 운영자 토큰, 첫 운영자 계정 ([업무 명세 2장](../spec.md#2-호출-주체와-인증)). 서비스 토큰(HomeFin·FinFlow)은 4단계에서 추가합니다.

- FinFlow 운영자 인증과 같은 방식이라 같은 관점으로 확인합니다: 정상(로그인), 예외(틀린 비밀번호), 경계(시도 제한 5번째·6번째), 보안(삭제된 운영자, 실패 기록의 이메일 원문, 운영자 API는 ADMIN만).
- 3단계에서 구현과 함께 자동화했습니다.

| ID          | 분류 | 확인 내용                                                                        | 기대 결과                                                                       | 위험 | 자동화                         | 관련 |
| ----------- | ---- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ---- | ------------------------------ | ---- |
| TC-AUTH-101 | 정상 | 운영자 로그인 (맞는 이메일·비밀번호)                                             | 200 `{token, expiresAt}`, 응답에 비밀번호·해시 없음, 그 토큰으로 운영자 API 200 | P1   | AuthApiTest                    |      |
